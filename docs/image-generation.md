# 카드뉴스 이미지 생성 선택

사이트 카드뉴스 화면의 **이미지 만드는 방식**에서 선택한다. 기본은 기존 무료 편집형이다. 선택만으로 API를 호출하지 않으며, 제작 버튼을 누르거나 저장한 스타일로 자동 제작할 때 실행한다.

| 방식 | 하는 일 | 비용·준비 |
| --- | --- | --- |
| 기존 편집형 | 한글·도형을 PNG로 배치 | 이미지 API 비용 없음, 바로 사용 |
| 내 PC · ComfyUI | 공개 모델로 삽화 생성 후 한글 배치 | 로컬 설치·모델 파일 필요, 전기·장비 사용. 외부 API 비용 없음 |
| OpenAI | gpt-image-2로 삽화 생성 후 한글 배치 | API 키·이용 권한·결제 필요, 사용량 과금 |

표지 1장(기본) 또는 모든 장에 삽화를 넣을 수 있다. OpenAI 품질은 낮음/중간/높음이다. 각 결과는 기존과 동일한 1080×1350 PNG이고 가로 슬라이드로 본다. AI에게 한글을 그리게 하지 않고 Noto Sans KR 글꼴로 별도 배치한다. AI 생성 삽화라는 표시를 남긴다. 생성 그림의 사실성·의미 일치는 사람이 게시 전에 확인해야 한다.

완성본에서는 **원고 유지하고 선택한 이미지 방식 적용**으로 문구를 다시 쓰지 않고 새 버전을 만든다. 기존 완성본은 유지한다. 현재 문구/디자인 수정본도 선택한 범위의 삽화를 새로 생성하므로 OpenAI 추가 비용이 생긴다. 같은 제작 실행 안에서 재시작·배치 재시도할 때는 저장한 삽화를 재사용한다.

**내 스타일로 저장**은 이미지 방식도 저장한다. 자동 제작은 하루 최대 3건·각 8장(KST)이며 저장한 제공자를 사용한다. OpenAI + 모든 장이면 자동 제작만으로 최대 24회 이미지 요청이다. 수동 제작의 앱 일일 제한은 없지만 제공자의 속도·결제 한도는 적용된다. 기존 완료 작업의 무료 설정을 자동으로 바꾸거나 다시 제작하지 않는다.

## 무료 모델 조사 — 2026-09-23

| 후보 | 라이선스 | 적합한 용도·제약 |
| --- | --- | --- |
| [Z-Image Turbo](https://huggingface.co/Tongyi-MAI/Z-Image-Turbo) | Apache 2.0 | 우선 검토 후보. 6B·적은 추론 단계로 사진/삽화 제작. 공식 안내의 16GB VRAM·H800 속도는 해당 하드웨어 조건이다. 이 PC의 속도를 뜻하지 않는다. |
| [FLUX.1 schnell](https://huggingface.co/black-forest-labs/FLUX.1-schnell) | Apache 2.0 | 12B, 1–4단계 생성. ComfyUI 워크플로로 교체 가능. dev 등 다른 모델과 라이선스를 혼동하지 않는다. 다운로드 시 제공자의 절차가 필요할 수 있다. |
| [Qwen-Image-2512](https://huggingface.co/Qwen/Qwen-Image-2512) | Apache 2.0 | 사진·세부 묘사를 비교할 후보. 실제 장비에서 속도/메모리 비교가 필요하다. 현재 커넥터의 기본 노드 허용 목록에 없는 전용 노드는 지원을 추가한 뒤 사용한다. |

[ComfyUI](https://github.com/Comfy-Org/ComfyUI)는 로컬 실행 도구이고 이미지 모델은 별도다. 로컬 실행과 유료 Comfy Cloud는 다르다. 공개 모델이라고 클라우드 GPU가 무료인 것은 아니다. 확인한 PC에는 Intel Arc Graphics가 있으나 실제 생성 성능은 아직 측정하지 않았다. 모델 설치·실제 샘플 비교 전에는 특정 모델의 품질이나 속도가 더 좋다고 단정하지 않는다.

## OpenAI 연결

키는 웹사이트·채팅·Git에 넣지 않는다. **로컬 처리 PC**에서 프로젝트 폴더를 열어 한 번 실행한다.

```powershell
.\scripts\configure-image-openai.ps1
```

이 스크립트는 숨김 입력으로 키를 받아 Git에서 제외된 `.local/worker.env`의 `OPENAI_API_KEY` 한 항목만 저장한다. 키를 출력하지 않고 이미지를 요청하지 않는다. 기존 파일의 다른 설정은 유지한다. 이 파일은 로컬 비밀 설정 파일이므로 공유하지 않는다.

진행 중인 제작이 없을 때 기존 처리기를 재시작하거나 다음 Windows 로그인 때 등록된 **AI Atlas Free Automation**이 다시 시작되면 적용된다. 실행 중인 처리기는 새 환경변수를 자동으로 읽지 않는다. 웹사이트에서 OpenAI를 선택하고 표지 1장으로 제작한다. Vercel 환경에만 키를 넣으면 로컬 처리기는 사용할 수 없다.

키 누락/권한 문제/한도 초과는 카드뉴스 상태에 표시한다. ChatGPT 서비스 이용권과 이미지 API 결제를 동일한 것으로 가정하지 않는다. [API 설정](https://developers.openai.com/api/docs/quickstart), [이미지 API](https://developers.openai.com/api/docs/guides/image-generation), [현재 요금](https://developers.openai.com/api/docs/pricing)을 확인한다.

## ComfyUI 연결

1. 처리 PC에 [공식 설치 안내](https://docs.comfy.org/installation/manual_install)를 따라 하드웨어에 맞는 ComfyUI를 준비한다. 이 변경은 ComfyUI·대형 모델을 자동으로 설치하지 않는다.
2. [Z-Image Turbo 공식 워크플로](https://docs.comfy.org/tutorials/image/z-image/z-image-turbo)를 불러온다. 안내된 diffusion_models의 `z_image_turbo_bf16.safetensors`, text_encoders의 `qwen_3_4b.safetensors`, vae의 `ae.safetensors`를 준비하고 먼저 ComfyUI에서 생성이 되는지 확인한다.
3. Z-Image Turbo는 기본 API 구성이 코드에 포함되어 있어 JSON을 직접 편집하지 않아도 된다. 다른 모델을 쓰려면 양성 프롬프트의 **CLIPTextEncode** text를 `__ATLAS_PROMPT__`로 바꾸고 출력은 **SaveImage 한 개**로 둔다. **File → Export (API)** 로 내보내 `.local/card-image-workflow.json`에 저장하면 기본 구성보다 우선한다. 일반 화면용 워크플로 JSON은 사용할 수 없다. 잘못된 설정 파일은 무시하지 않고 오류로 표시한다.
4. ComfyUI를 `127.0.0.1:8188`에 바인딩해 실행한다. 연결 방향은 **로컬 작업 처리기 → 같은 PC의 ComfyUI**다. 사이트 브라우저가 ComfyUI로 직접 접근하지 않으며 외부 공개 포트가 필요 없다. 포트를 바꾸면 `.local/worker.env`의 `ATLAS_COMFYUI_PORT`를 변경하고 처리기를 재시작한다.
5. 사이트에서 **내 PC 이미지 AI · ComfyUI**, **표지만**을 선택하고 제작한다. 처음에는 모델 로딩 시간이 추가된다.

커넥터는 배치 1·1024 정사각형, 임의 시드, 안전한 출력 파일명으로 실행한다. 중앙 피사체를 넓은 카드 영역에 맞춰 자른다. 표준 로더·인코더·샘플러·디코더·저장 노드만 허용하며 사용자 정의 노드, 유료 파트너 노드, 임의 외부 URL은 받지 않는다. 모델 파일은 모델 폴더 바로 아래 safetensors 이름을 사용한다. FLUX schnell도 같은 API 내보내기 방식으로 교체하되 현재 허용 노드인지 확인한다.

## 중단·오류 처리

- 장별 원본 삽화와 최종 PNG를 비공개 저장소에 저장한다. 최종 배치 재시도에는 저장한 삽화를 다시 쓴다.
- ComfyUI 요청 번호가 저장된 경우 재개 시 같은 요청의 결과를 조회한다. 8분 동안 결과가 없으면 원인을 확인할 수 있도록 멈추며 **이어서 제작**으로 다시 조회한다. 큐 전체 삭제/중단은 하지 않는다.
- OpenAI 요청 중 연결이 끊기거나 성공 응답 저장 여부가 불명확하면 자동 재요청하지 않는다. 제공자 기록을 확인하고 필요할 때 설정을 바꿔 새 버전을 요청한다. 이 경우 추가 과금 가능성을 사용자가 판단한다.
- 연결 실패 시 다른 제공자나 무료 도형으로 조용히 전환하지 않는다. 기존 무료 제작·완성본·일일 한도 정책은 유지한다.
- 자동 검수는 파일 크기/해시/한글 배치/원문과 문구 일치다. AI가 그린 그림의 의미·사실성을 자동 검증했다고 표시하지 않는다.
