# 사용 흐름 점검 — 2026-09-22

## 사용자가 하는 일

자료 추가 → 자동 정리 → 카드부터 읽기. 기본 메뉴는 내 자료·새 소식·지식 노트다. 기존 즐겨찾기, 읽음 표시, 지도, 휴지통, 원문·메모, 상세 분석, 내보내기, Obsidian 기능은 유지한다. 고급 옵션과 운영 정보는 필요한 화면에서 펼쳐 사용한다.

## 검증

- 전체 자동 테스트 55개와 프로덕션 빌드 통과. 저장 시 자동 예약, 예약 실패 시 원문 보존, 저장만 하기, 중복 방지, 다른 계정 차단을 포함한다.
- PC·모바일 브라우저에서 기본 메뉴, 카드 이동, 상세 분석 연결, 미완성 자료 안내, 로그인 경계 확인. 브라우저 콘솔 오류 없음.
- 실제 인증 API로 검증용 합성 자료 저장, 자동 예약, 중복 방지, 메모·즐겨찾기 저장 확인.
- 중단 상태로 만든 합성 자료가 재시도 후 본문 검증까지 도달함을 확인. 이전의 `ALREADY_RUNNING` 재시도 막힘이 재현되지 않았다.
- 외부 AI의 짧은 요청은 성공했으나, 자료 작성 요청은 연결 프로그램의 90초 제한에 의해 반복 중단된 것을 해당 실행 로그와 설치된 코드에서 확인했다. 해당 호출에만 대기 시간 설정을 적용했으며 외부 AI 가용성과 원문 사이트의 읽기 권한은 별개다.
- 배포 점검 스크립트는 무인증 자료·계정·자동화·지식 API 및 비밀번호 설정 차단, 공개 설정과 HTML의 서버 키 미노출을 확인한다.

공개 페이지에 없는 본문은 직접 보완해야 한다. 무인증 설정, 소유자 검증, URL 접근 제한, 원문을 도구 없이 처리하는 경계와 비밀값 분리는 유지한다.
